# Weather App

A simple and responsive web application that provides real-time weather information and a detailed hourly forecast.

## 🚀 Features

* **Current Weather**: View the exact temperature, weather conditions, and humidity right now.
* **Hourly Forecast**: Check upcoming weather changes hour by hour to plan your day.
* **City Search**: Look up the current weather for any city worldwide.
* **Responsive UI**: Clean design that works seamlessly on both mobile devices and desktops.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript
* **API**: Weather Data API

## 💻 Getting Started

### Prerequisites
You will need an API key from your weather data provider.

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```

2. Open the project folder:
   ```bash
   cd weather-app
   ```

3. Open the `index.html` file directly in your browser, or run it using a local server extension (like Live Server in VS Code).

## 📝 How to Use

1. Enter the name of a city in the search bar.
2. Click the search button.
3. View the current conditions and the hourly breakdown instantly.
